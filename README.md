# Versena downloads

Versena is a local-first writing app from Thorn & Reason. This repository contains installers and signed update information; the application source is private.

## Current beta: 0.1.3-beta.4

This release uses the regenerated icon family, with matching navy backgrounds in macOS Default and Dark styles.

- [Apple Silicon Mac installer](https://github.com/Thorn-and-Reason/Versena-releases/releases/download/v0.1.3-beta.4/Versena_0.1.3-beta.4_darwin-aarch64.dmg)
- [Intel Mac installer](https://github.com/Thorn-and-Reason/Versena-releases/releases/download/v0.1.3-beta.4/Versena_0.1.3-beta.4_darwin-x86_64.dmg)
- [Windows x64 installer](https://github.com/Thorn-and-Reason/Versena-releases/releases/download/v0.1.3-beta.4/Versena_0.1.3-beta.4_windows-x86_64-setup.exe)
- [Linux x64 AppImage](https://github.com/Thorn-and-Reason/Versena-releases/releases/download/v0.1.3-beta.4/Versena_0.1.3-beta.4_linux-x86_64.AppImage)

Existing users can update through the Thorn & Reason Launcher or choose **Check for updates** in Versena. Builds without the updater need one manual installation. Save your work and quit Versena before replacing it manually. Projects remain local files.

Mac packages are ad-hoc signed and have not been notarised by Apple. Windows packages have no Authenticode signature. Package signatures verify the update separately from operating-system publisher trust. Full desktop and accessibility acceptance has not been repeated on every platform.
